Disco

Return

I did the branding for Team Disco, a small group i'm a part of that makes vanilla plus minecraft resourcepacks. The group is, at the time of writing, currently in the process of creating 3D versions of all the items in Minecraft.

Project Created: 10/02/2026

Page Written: 21/02/2026





You can see the designs in use here:

  • discord.gg/g4ttZaSVq2
  • modrinth.com/organization/team-disco




Logo

I made the logo in a similar style to the one used by Minecraft to tie it to the game, and also because the shape leaves open opportunities for adaptations like a mascot skin's head or modded block without looking out of place in-game.


To achieve a shiny effect, I paid a lot of attention to maximising the amount of juxtaposition in the tile colours, so it dosen't look matte or smudgy but like a sharp gem with lots of nice contrast.





Discord Server

The main place other than on Modrinth that the branding would be in use was the Discord, so I made a quick server banner and and icon.





Logo Animation

I made an animated end screen for things like showcase videos and trailers.

This was very simply done in After Effects by just manually keyframing the fill colours of each square to give a sparkly effect. The animation was inspirted by the Lucasfilm logo. I really liked how the light moves around to create a shimmery effect and bring more motion into the animation, instead of a static light just increasing in intensity.




The animation can also be used as a standalone element where it doesn't make sense to have the background and text.



Conclusion

It was a pretty quick and simple project, but I thought i'd still write a little page about it on my website anyways.

I put it under the pixel art section because it makes sense to be grouped with the other stuff, and I don't want to make a whole new page on my website just for graphic design since this would be the only project there.
